Hệ thống sử dụng Firebase Firestore làm cơ sở dữ liệu duy nhất. Dữ liệu POI được khởi tạo qua hàm SeedDataToCloudAsync(), các trường thống kê được cập nhật real-time bằng FieldValue.increment().

Phần 03

Android Foreground Service & Geofencing

Chức năng trải nghiệm cốt lõi của App: phát hiện khách lạc đến gần quán và tự động phát giọng thuyết minh, hoạt động ngay cả khi màn hình khóa.

Android Foreground Service (AndroidLocationService.cs): Được khai báo trong AndroidManifest.xml với quyền FOREGROUND_SERVICE_LOCATION. Hệ thống hiển thị thông báo dai dẳng (persistent notification) để Android OS không đầy service ra khỏi bộ nhớ.

Quá trình kích hoạt (Life-cycle)

1. Khởi động Service — StartTracking()

Khi quyền GPS được cấp, GpsService.StartTracking() tự động gọi StartForegroundServiceCompat() trên Android.

2. Quét GPS mỗi 10 giây — OnLocationChanged()

Service gọi CheckGeofences(lat, lng) để tính khoảng cách Haversine tới từng POI.

3. Kích hoạt Geofence — HighlightPoiOnMap(poi.Id)

Nếu khoảng cách ≤ poi.Radius và cờ HasAutoPlayed == false: Highlight Marker, gọi CallCrossTTS() phát tiếng.

4. Tải cờ chống Spam — ResetAutoPlayFlag()

Khi thiết bị rời xa hơn poi.Radius + 30m, cờ HasAutoPlayed được đặt lại về false.

Phần 04

Web Portal, Admin Dashboard & Trải Nghiệm Mỏ Rộng

QR Code “Không chạm” (Web)

Khách hàng không bị bắt buộc tải App. Chủ quán in mã QR từ Dashboard đặt tại bàn. Khách dùng camera gốc quét mã để mở trang thông tin quán trên trình duyệt.

Thuyết Minh TTS (Web bằng SpeechSynthesis)

Sau khi quét mã QR, khách nhấn 1 nút. Trình duyệt gọi SpeechSynthesisUtterance đọc mô tả các ngữ điệu (Vi, Anh, Nhật, Trung) và ghi nhận audioListenCount.

Foreground Service TTS (App Android)

MAUI App sử dụng ITextToSpeech để phát giọng thuyết minh ngay cả khi màn hình khóa. Gây phát thiết bị được ghi vào AppPlayCount trên Firestore (Atomic).

Admin Dashboard + Heatmap

Admin xem thống kê tài khoản, giám sát thiết bị đang online qua app_live_sessions và xem Bản đồ nhiệt (Leaflet Heatmap) phân bố lượt nghe thực tế trên đường phố.

// Web: TTS + Ghi nhận Thống kê (Firebase)
function startReading() {
    const utterance = new SpeechSynthesisUtterance(text);
    utterance.lang = getBestVoice(currentLang);
    window.speechSynthesis.speak(utterance);

    // Atomic increment trên Cloud
    updateDoc(docRef, { audioListenCount: increment(1) });
}

// App Android: Foreground Service gọi TTS + Ghi AppPlayCount
async Task CallCrossTTS(string text, string lang) {
    await TextToSpeech.Default.SpeakAsync(text, new SpeechOptions { Locale = lang });
    await DatabaseService.IncrementAppPlayCountAsync(poiId);
}
