Phần 01

Kiến Trúc Thành Phần Hệ Sinh Thái

Hệ thống đã được nâng cấp toàn diện từ cấu trúc Offline sang kiến trúc Điện toán đám mây (Cloud-based), phân quyền rõ ràng 3 cấp: Khách - Chủ - Admin.

☁️
Cloud Firestore
Chuyển đổi hoàn toàn từ SQLite sang Firebase. Dữ liệu POI, Tọa độ và Trạng thái người dùng được đồng bộ thời gian thực cho mọi thiết bị.
🌐
Web Dashboard
Cổng thông tin cho Chủ quán đăng ký (tích hợp phí 500k/200k), quản lý mô tả đa 4 ngôn ngữ và sinh mã QR động.
🔊
Web Speech API
Hệ thống chuyển đổi văn bản thành Giọng nói nhúng trực tiếp vào Web, cho phép nghe ngay lập tức không cần cài App.
🛡️
Admin Control
Cơ chế quản trị viên khóa tài khoản (Kick-out). Nhờ Firebase onSnapshot, thiết bị vi phạm sẽ bị văng ra ngay trong 0.5s.
🗺️
Mobile Maps
Ứng dụng .NET 9 MAUI vẽ bản đồ Google Maps native, tự động tracking Geofence khi người dùng đi vào phạm vi quán.
📊

Phần 03

Cơ Chế Auto-Tracking & Kích Hoạt Âm Thanh

Ứng dụng không chỉ có dạng list nhàm chán. Chức năng chính là quét tương tác để "Ngạc nhiên" phát âm thanh cho du khách.

Geofencing Cục bộ: Đo đạc bằng CalculateDistance(p, Km) * 1000 vòng quét mặc định của mỗi quán là 30 mét. Khi thiết bị xâm nhập, Cờ HasAutoPlayed được dựng lên để tránh lặp (Spam).

Quá trình kích hoạt (Life-cycle)

1. Tín Hiệu Nền - StartTracking()

GPS Engine đẩy luồng sự kiện mỗi giây (1s). Cập nhật mapVinhKhanh.MoveToRegion và toạ độ lõi _userScanCircle.

2. Quét Toàn Mảng & Tính Toán Haversine

foreach (var p in _vinhKhanhPois): Cập nhật biến DistanceInMeters real-time.

3. Kích Hoạt Điểm Đến (Radius Breach)

Nếu khoảng cách ≤ poi.Radius và chưa phát -> Đổi cờ Status Trạng Thái màu Xanh lá -> Ép List hiện Tab "Gần Đây" -> OrderBy Distance.

4. Khóa chống Spam (Reset Flag)

Nếu khoảng cách vượt ra xa quán hơn 30m so với Radius (poi.Radius + 30m), thiết bị tiến hành dỡ cờ HasAutoPlayed = false, sẵn sàng lần báo tiếp theo.

Phần 04

Trải Nghiệm Dịch Vụ Web-App Mở Rộng

QR Code "Không chạm"

Khách hàng không bị bắt buộc tải App. Chủ quán in mã QR từ Dashboard đặt tại bàn. Khách dùng camera gốc của điện thoại quét mã để mở thẳng trang thông tin quán (index.html).

Thuyết Minh Rảnh Tay

Sau khi Quét mã, khách chỉ việc nhấn 1 chạm. Trình duyệt tự động gọi SpeechSynthesisUtterance đọc mô tả chuẩn ngữ điệu (Vi, Anh, Nhật, Trung) nhờ AI của hệ điều hành.

Auto-Tracking Thống kê

Quá trình "Quét QR và Nhấn Nghe" sẽ tự động kích hoạt hàm increment() trên Firebase. Đẩy số liệu lượt nghe thẳng về bảng Dashboard cho Admin & Chủ quán phân tích thị hiếu.

// Kịch bản Web Speech API và Ghi nhận Thống kê (Firebase)
function startReading() {
    const text = resDescEl.innerText;
    let utterance = new SpeechSynthesisUtterance(text);
    utterance.lang = getBestVoice(currentLang);

    // Call OS Level Engine
    window.speechSynthesis.speak(utterance);

    // Tăng bộ đếm Real-time trên Cloud
    db.collection("restaurants").doc(resId).update({
        audioListenCount: firebase.firestore.FieldValue.increment(1)
    });
}
